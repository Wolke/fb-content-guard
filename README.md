# 清朗 · FB 色情內容遮擋

Chrome 擴充功能，目標是安裝後同意分析就能使用，**不需要登入、API key、本機配對碼、Node.js 或終端機**。

**0.2.4 已於 2026-11-04 提交 Chrome 商店審查，尚未核准／發布。** 既有公開版為 0.2.3；新版核准後採手動發布。完整 CI 通過。真實 FB 已確認可經雲端送進擴充功能本機模型，不確定結果保持隱藏；本次尚未確認成功分類與放行，完整驗收仍待完成。

開發版 **0.2.5** 新增獨立 API 診斷頁，預設關閉，可查看安全分類欄位與最後隱藏原因。使用方式及限制見 [0.2.5 更新紀錄](store/RELEASE-0.2.5.md)。尚未送審。

## 新版使用方式（部署與商店更新完成後）

1. 安裝清朗。
2. 開啟設定，閱讀並同意將首頁貼文與右側贊助廣告文字與圖片交由清朗雲端服務及 OpenAI 分析。
3. 儲存後重新整理 Facebook 首頁。

已辨識的貼文會先遮擋，未被模型標記後再顯示。正式版會直接隱藏檢查中、疑似色情、無法檢查或超過免費用量的貼文，不插入提示卡或空白佔位；開發版才顯示原因、重試與手動顯示按鈕。設定頁可關閉遮擋、撤回分析同意與檢查服務狀態。舊本機版的分析同意不會自動延用到雲端版。

## 本機加強圖片檢查（0.2.4 實驗功能）

1. 在擴充功能設定按「開啟本機模型設定」。
2. 按「下載／啟用本機模型」，等待就緒；若不支援，不要啟用實驗開關。
3. 返回擴充功能設定，勾選「加強圖片檢查」並儲存，保留模型分頁。

預設關閉。此模式在雲端放行後逐張加做本機圖片檢查，全部通過才顯示；文字仍由雲端檢查，雲端額度不會增加。不另收本機推論 API 費用，但需要硬體、下載空間與運算時間。支援能力以實際 Chrome 的 `LanguageModel.availability()` 為準。

模型分頁關閉、休眠、回覆無效、不確定、內容超出容量或整則超過 120 秒，一律保持隱藏。關閉實驗功能會回到既有雲端流程。切換設定會清除舊分類快取並重新檢查。模型原文不寫入日誌或儲存；只接受受 JSON Schema 約束的三種結果。這不是專用 OCR，中文與性暗示判斷仍可能誤判。

參考：[Chrome Prompt API](https://developer.chrome.com/docs/ai/prompt-api)。

## 功能範圍

- 僅桌面版 `www.facebook.com` 首頁 `/`、`/home.php`，不支援群組、個人頁、Messenger 或手機 App。
- 分析貼文容器的文字及已載入靜態 JPEG、PNG、WebP 圖片，以及可轉換的內嵌靜態 SVG 圖示；影片先檢查封面，沒有封面時嘗試讀取單張畫面；通過後顯示靜態預覽，需手動選擇播放整段未檢查的影片。「查看更多」與「+N 張照片」不會單獨造成阻擋；只檢查目前已載入的部分，展開後再檢查新增內容。無可讀影片預覽及動畫保持遮擋。
- 每則最多 12 個不同圖片來源（含頭像、背景圖與圖示）、16,000 文字字元。圖片下載上限 4 MiB，保留完整畫面縮至最長邊 512 像素的 JPEG；單張轉換後最多 128 KiB，合計 512 KiB。縮圖可能影響小字和細節的判斷。
- 遠端圖片下載限 HTTPS Facebook CDN；內嵌靜態 SVG 在瀏覽器轉成 JPEG，不攜帶 Cookie、不跟隨轉址。影片單張畫面只在瀏覽器允許讀取時擷取，不繞過跨來源限制。不擷取整頁截圖，也不點擊 Facebook 的隱藏或檢舉。
- Facebook 版面可能改動，模型可能誤判／漏檢。此工具不能保證阻擋全部色情內容，也不是無法繞過的家長監護工具。
- 模擬測試不代表真實 Facebook 適配或模型準確率已通過驗收。

## 資料與免費額度

資料流為擴充功能 → 清朗 HTTPS 雲端服務 → OpenAI Moderation。開發者在雲端保管 API key，終端使用者看不到，也不需申請金鑰。

使用者同意後才開始新的內容分析。服務不把貼文原文、圖片或原始網址寫入應用資料庫／日誌。為防止匿名濫用，後台使用短期匿名 session、當日 IP 派生碼及請求時間做限流。一般工作階段一小時到期；資料庫計數預定 48–49 小時內清除，平台備份另依平台政策。詳見 [雲端版隱私權政策](store/PRIVACY-CLOUD.md)。

目前預設：全站每日最多 1,000 次圖片／文字分類、每分鐘 15 次；單一網路來源每日 200 次／每分鐘 15 次；單一匿名 session 每日 100 次。多圖貼文逐張檢查，每張計一次；純文字貼文計一次。整則貼文的所需額度會一次預留，不足時不送往 OpenAI；失敗或提前判定遮擋也不退還預留額度。全站硬上限不能因重新安裝或後台重啟而歸零。

匿名限流不能完全阻止分散式濫用，遭濫用時可能耗盡免費額度而暫停服務。OpenAI 帳戶配額、Workers CPU／請求、D1 讀寫限制也可能更早到達。**不保證免費無限用量、不自動啟用付費方案或模型。**

## 開發者操作（一般使用者不需要執行）

需要 Node.js 22.13+、Python 3。首次安裝開發依賴：

```bash
npm ci
npm test
npm run test:runtime
npm run package:dev
```

`test:runtime` 在本機 Cloudflare workerd 和 D1 執行，所有 OpenAI 回應均為模擬。可選的 Chrome 合成測試：

```bash
npm install --no-save playwright
npx playwright install chromium
npm run test:browser
npm run test:images
```

`CHROME_PATH` 可指定獨立無頭 Chrome 執行檔；`PLAYWRIGHT_MODULE` 可指定既有 Playwright 模組檔案。

- [執行計畫](cloud/EXECUTION-PLAN.md)
- [後台架構與完成狀態](cloud/README.md)
- [免費部署操作手冊](cloud/DEPLOY.md)
- [正式部署進度](cloud/DEPLOYMENT-STATUS.md)
- [雲端版測試紀錄](cloud/TEST-REPORT.md)

部署完成後才由開發者執行：

```bash
python3 scripts/configure_cloud.py https://實際部署的主機名稱
npm run package
```

設定工具會檢查服務版本，再將固定主機加入最小權限。正式套件檢查會拒絕未配置的網址和 localhost 權限；開發包檔名／顯示名稱會標記勿上架。能打包不代表已通過真實驗收。

`server/` 保留 0.1.0 本機服務作回歸測試與開發參考，不屬於新版的使用流程。商店 ZIP 不包含伺服器原始碼、開發工具或秘密。

## 0.2.2 限流修正（尚未提交商店）

瀏覽器內所有 FB 分頁共用分析排程，每 65 秒最多預留 15 個圖片／文字分類單位。背景服務重啟後，當次瀏覽器工作階段的計數仍會保留。遇到雲端限流或暫時連線失敗時，貼文維持隱藏並自動重試；連續失敗逐步延長等待，最長約 30 分鐘。這不會提高後台的每分鐘／每日限制，也不能保證每日額度用完後立即恢復。

設定頁分開顯示檢查中、等待額度、等待內容及讀取失敗的數量；錯誤原因只顯示在設定頁，不會插入正式版動態牆。尚未載入的內容等待頁面更新後再檢查，不以空內容呼叫 API。

## 正式版與開發版的畫面

`npm run package` 產生正式版，首頁只顯示通過檢查的內容。`npm run package:dev` 產生帶有 `-development` 版本標記的獨立開發 ZIP，保留檢查狀態、錯誤原因、重試與手動顯示按鈕。兩者使用同一套判斷邏輯；設定頁仍可查看狀態或關閉遮擋。若要以未封裝模式除錯，請解壓開發 ZIP 並載入該資料夾。

## 0.2.3 右側贊助廣告（尚未提交商店）

首頁掃描新增右側廣告圖片卡片，逐則檢查文字與圖片。未完成、限流、讀取失敗或判定需遮擋的內容在正式版保持隱藏。好友邀請與聯絡人的 Facebook 個人檔案連結不送去分析。可辨識的 RightRail／Sponsored pagelet，以及有「贊助／Sponsored」標題的 complementary 區域受到支援；FB 若更改結構仍可能需要適配。此變更不提高服務額度，也不保證分類不會漏判。
