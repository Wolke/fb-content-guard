清朗 · FB 色情內容遮擋 — 雲端版隱私權政策

草案日期：2026-10-15。適用版本：0.2.0 雲端版。正式部署與商店更新完成後適用；0.1.0 本機版請參考原有政策。

清朗由 Wolke 開發，單一用途是在桌面版 Facebook 首頁檢查色情內容並調整貼文在本機的顯示方式。本產品不是 Meta、Facebook 或 OpenAI 官方產品。

使用者同意與處理內容

只有在使用者啟用功能並同意本版雲端分析後，擴充功能才開始傳送新的貼文分析要求。舊版對本機服務的同意不會自動授權雲端分析。

程式讀取已辨識貼文容器中的文字和已載入圖片，可能包含作者、頭像、留言、介面文字，以及貼文中的個人識別、健康、財務／付款、位置資料或通訊截圖。程式不會先識別並刪除所有敏感資訊；這些內容僅用於色情分類，不用來建立個人敏感資料檔案。

靜態圖片從 Facebook CDN 下載，不攜帶 Facebook Cookie。完整畫面縮為最長邊 512 像素的 JPEG 後，連同貼文文字透過 HTTPS 傳至清朗後台，再傳到 OpenAI Moderation API。沒有傳送原始 Facebook 圖片網址、完整頁面截圖、Facebook 密碼或 Cookie。

程式不讀取瀏覽器歷史紀錄資料庫；目前頁面網址和部分貼文連結僅在分頁記憶體用於辨識內容及導覽。

接收資料的服務

  • 清朗後台由 Cloudflare Workers 處理請求，會暫時接觸提交的文字與圖檔，以完成轉送、大小驗證和用量限制。
  • OpenAI API 接收用於分類的文字與圖檔；處理及保留方式依其 API 資料政策，本產品不保證零留存。
  • Cloudflare 為連線及安全運作會處理網路資料，適用其 隱私權政策。

開發者不將貼文原文、圖片、原始圖片網址或 API key 寫入應用程式日誌／持久資料庫，不使用分析追蹤 SDK、廣告或資料販售。無法以此承諾第三方平台完全沒有其自身的安全／連線紀錄。

設定、匿名連線與保留時間

  • 啟用開關與雲端分析同意版本存於 Chrome 本機儲存，無 Chrome 同步。
  • 免登入：不要求姓名、電子郵件或帳號。擴充功能自動取得匿名短期連線憑證，存於 Chrome 擴充功能的工作階段儲存，僅可信任的背景服務／設定頁可讀取，不提供給 Facebook 網頁。
  • 憑證最長一小時有效，到 UTC 換日時提早到期；網路來源改變需重取。關閉瀏覽器後工作階段儲存會清除。
  • 為限制匿名濫用，後台將連線 IP 與當日日期透過秘密金鑰計算派生識別碼，資料庫僅存派生碼、隨機 session 識別碼、操作類型與請求時間，不存原始 IP。派生碼屬用量控制資訊，不宣稱完全不可識別。
  • 用量紀錄由每小時清除工作移除超過 48 小時的資料，正常情況保留最多約 49 小時；清除工作失敗時須排除故障後補刪。Cloudflare D1 平台備份／復原副本的保留另依其平台設定與政策。
  • 分頁最多暫存 300 筆內容雜湊及分類結果，重新整理或切換網址時清除。
  • OpenAI API key 和服務簽章秘密只由開發者設定在後台，不包含在擴充功能內。

使用者控制與刪除

可隨時撤回分析同意、關閉功能或解除安裝。撤回同意會清除擴充功能持有的匿名連線資料並停止新分析；已送往後台或 OpenAI 的請求可能仍會完成。每則貼文可以手動顯示。

解除安裝移除本機設定；後台短期用量紀錄依上面的保存期限到期清除，避免重新安裝繞過服務限額。Chrome、Facebook、作業系統和服務供應商自身的資料處理不由本擴充功能控制。

使用限制與聯絡

資料僅用於色情內容分析、服務傳輸與必要的用量／防濫用控制，不出售、不用於廣告、信用評估或貸款。使用與轉移資料遵守 Chrome Web Store User Data Policy，包括 Limited Use 限制。

一般隱私問題請透過 GitHub Issues 聯絡 Wolke。此為公開空間，請不要附上貼文、圖片、金鑰或其他私人資訊。
