清朗會先遮住 Facebook 首頁已辨識的貼文，再經你的同意，將文字與靜態圖片交由 OpenAI 檢查色情內容。

查看安裝說明閱讀隱私權政策
目前為 0.1.0 原型，Chrome Web Store 尚未上架。
需要桌面版 Chrome、Node.js 22 以上、本機服務，以及你自己的 OpenAI API key。尚未完成真實 Facebook 與 OpenAI API 的端到端驗收。

如何運作

  1. 辨識 Facebook 首頁貼文，在檢查前先遮住內容。
  2. 經你同意後，由本機服務將貼文文字與圖片送往 OpenAI。
  3. 未被模型標記的內容顯示；疑似色情或無法檢查的內容保持遮擋。你可以手動展開。

保留你的控制權

API key 存在你的電腦；開發者不營運接收貼文的中央伺服器。你可以撤回分析同意、停用或解除安裝。傳往 OpenAI 的內容依其 API 資料政策處理，並非保證零留存。

使用前請了解

目前只支援桌面版 Facebook 首頁的文字與已載入靜態圖片。影片不會自動放行。Facebook 版面變動可能造成漏檢，模型也可能誤判；無法保證所有內容都能在出現前遮住。

本版不會自動點擊 Facebook 的隱藏、檢舉或其他操作。完整功能限制與設定方式請參考 公開原始碼與 README。
