# 0.2.1 更新紀錄

更新日期：2026-10-22。尚未上傳 Chrome Web Store；商店目前公開版本為 0.2.0（當日控制台確認）。

## 使用者可見的變更

- 貼文有「查看更多」或「+N 張照片」時，直接檢查已載入的文字與圖片，不要求先展開全部內容。
- 使用者展開貼文、載入新圖片或 Facebook 更換貼文內容後，重新遮擋並檢查新增內容。
- 首頁影片先檢查封面，無封面時嘗試擷取可讀取的單張畫面。通過後顯示靜態預覽，播放整段影片需手動選擇。
- 不把單張預覽判定當成整段影片通過；無法取得預覽時仍保持遮擋。
- 同步更新設定頁、商店說明草稿與雲端隱私權政策；未增加權限或改動服務額度。
