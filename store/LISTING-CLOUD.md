## 商品說明

清朗會先遮住已辨識的 Facebook 首頁貼文及可辨識的右側贊助廣告卡片，在你同意後，將文字與縮小的靜態圖片交由清朗雲端服務和 OpenAI 分析色情內容。未被模型標記的內容會顯示；檢查中、疑似色情、無法檢查或達到服務用量上限的貼文與廣告直接隱藏，不在動態牆顯示錯誤卡片或佔位。

不需要登入，不需要 API key、配對碼或安裝其他程式。第一次安裝請閱讀雲端資料處理說明並主動同意，再重新整理 Facebook 首頁。你可以隨時撤回同意或關閉遮擋。

掃描首頁貼文及可辨識的右側圖片廣告卡片；不把旁邊的好友邀請或聯絡人當成廣告分析。只適用桌面版 Facebook 首頁的文字、已載入靜態圖片及影片預覽。影片先檢查封面或可讀取的單張畫面，通過後顯示靜態預覽；整段影片尚未檢查，需要手動選擇播放。有「查看更多」或更多照片時，先檢查目前載入的部分；展開後再檢查新增內容，不會自動展開整則貼文。不支援 Reels 專用頁面、動態圖片、群組、Messenger 或手機 App。圖片完整畫面縮小後分析，可能影響細節判斷；模型和貼文辨識可能誤判、漏檢，無法保證完全阻擋色情。這不是無法繞過的家長監護工具。

免費服務有用量及速率限制。暫時限流時會排隊並自動重試；等待額度或內容載入時保持隱藏，排隊不會增加每日額度。只調整本機顯示，不自動向 Facebook 隱藏、檢舉或發送訊息。與 Meta、Facebook、OpenAI 無官方隸屬關係。

## 單一用途

在使用者同意後，檢查 Facebook 首頁貼文及可辨識的右側贊助廣告文字與圖片，將疑似色情或尚未完成檢查的內容保持隱藏。

## 權限理由

- storage：保存功能開關、雲端分析同意版本及自動取得的短期匿名 session，另以工作階段儲存保留跨分頁共用的分析計數與冷卻時間。不使用 Chrome 同步，session 僅可信任擴充功能環境可讀取。
- facebook.com：辨識首頁貼文與右側廣告卡片並加入遮罩，讀取已載入文字和圖片。
- fbcdn.net：下載貼文與廣告靜態圖片，沒有 Facebook Cookie、不跟隨轉址，縮圖後分析。
- 正式服務 HTTPS 主機：請求短期匿名 session、分析及服務狀態。實際主機為 fb-content-guard.wolkesau.workers.dev；不要求 localhost 權限。
- 無遠端可執行程式碼：服務只回傳 JSON 分類結果和短期憑證，沒有遠端 JavaScript、Wasm 或 eval。

## 資料揭露更新

使用者貼文與廣告內容會由開發者部署於 Cloudflare 的服務暫時處理，再轉交 OpenAI。維持對貼文可能含個人識別、健康、財務／付款、通訊及位置資料的保守揭露；另說明匿名 session、網路 IP 及其派生碼的防濫用用途，不可宣稱無後台接收資料或完全匿名。

隱私權網址沿用 `https://wolke.github.io/fb-content-guard/privacy-cloud.html`，新版政策新增右側廣告與跨分頁排程的說明。上傳時沿用既有資料揭露，並核對三項聲明與實作一致。

## 0.2.4 實驗功能補充

自 0.2.4 起，可選擇啟用預設關閉的「加強圖片檢查」實驗功能。雲端放行後，同一批縮小圖片再由 Chrome 內建 Gemini Nano 在本機檢查色情與性暗示；純文字貼文仍走原有雲端流程。這不是離線模式，雲端同意與額度限制仍適用。首次啟用需由使用者在擴充功能模型分頁下載／啟用 Chrome 模型，並保留該分頁。這道本機推論不把內容傳給 Google，也不保存圖片、文案或模型原始回覆；實驗開關存於 Chrome 本機設定。中文辨識可能出錯，模型不可用、結果不確定或逾時時保持隱藏。
