## 商品說明

清朗會先遮住已辨識的 Facebook 首頁貼文及可辨識的右側贊助廣告卡片，在你同意後，將文字與縮小的靜態圖片交由清朗雲端服務和 OpenAI 分析色情內容。未被模型標記的內容會顯示；檢查中、疑似色情、無法檢查或達到服務用量上限的貼文與廣告直接隱藏，不在動態牆顯示錯誤卡片或佔位。

不需要登入，不需要 API key、配對碼或安裝其他程式。第一次安裝請閱讀雲端資料處理說明並主動同意，再重新整理 Facebook 首頁。你可以隨時撤回同意或關閉遮擋。

掃描首頁貼文及可辨識的右側圖片廣告卡片；不把旁邊的好友邀請或聯絡人當成廣告分析。只適用桌面版 Facebook 首頁的文字、已載入靜態圖片及影片預覽。影片先檢查封面或可讀取的單張畫面，通過後顯示靜態預覽；整段影片尚未檢查，需要手動選擇播放。有「查看更多」或更多照片時，先檢查目前載入的部分；展開後再檢查新增內容，不會自動展開整則貼文。不支援 Reels 專用頁面、動態圖片、群組、Messenger 或手機 App。圖片完整畫面縮小後分析，可能影響細節判斷；模型和貼文辨識可能誤判、漏檢，無法保證完全阻擋色情。這不是無法繞過的家長監護工具。

免費服務有用量及速率限制。暫時限流時會排隊並自動重試；等待額度或內容載入時保持隱藏，排隊不會增加每日額度。只調整本機顯示，不自動向 Facebook 隱藏、檢舉或發送訊息。與 Meta、Facebook、OpenAI 無官方隸屬關係。

自 0.2.4 起，可選擇啟用預設關閉的「加強圖片檢查」實驗功能。雲端放行後，同一批縮小圖片再由 Chrome 內建 Gemini Nano 在本機檢查色情與性暗示；純文字貼文仍走原有雲端流程。這不是離線模式，雲端同意與額度限制仍適用。首次啟用需由使用者在擴充功能模型分頁下載／啟用 Chrome 模型，並保留該分頁。這道本機推論不把內容傳給 Google，也不保存圖片、文案或模型原始回覆；實驗開關存於 Chrome 本機設定。中文辨識可能出錯，模型不可用、結果不確定或逾時時保持隱藏。

自 0.2.5 起，可在「查看 API 與判定紀錄」主動啟用預設關閉的診斷功能，查看每次檢查的 API 階段、HTTP 狀態、耗時、分類旗標與分數，以及最後隱藏原因。只記錄啟用後的新檢查，不記錄貼文文字、圖片、網址、金鑰或模型原始回覆。最多在 Chrome 工作階段儲存保留 600 筆事件，讀寫時清除超過 6 小時的紀錄；關閉記錄、手動清除或結束瀏覽器會清除。可主動匯出 JSON 至本機，背景主控台同步輸出診斷；匯出與主控台副本需另行管理。診斷不增加模型呼叫，不改變分類規則；正式版動態牆仍不顯示除錯卡。

商店截圖使用合成動態牆與模擬分類，沒有使用真實使用者貼文。第一張為正式版；另一張含原因、重試及手動顯示按鈕的畫面為開發版除錯示意，正式版不會在動態牆顯示這些提示卡；0.2.5 的診斷功能放在獨立設定頁。

## 單一用途

在使用者同意後，檢查 Facebook 首頁貼文及可辨識的右側贊助廣告文字與圖片，將疑似色情或尚未完成檢查的內容保持隱藏。

## 權限理由

- storage：保存功能開關、本機加強圖片檢查開關、雲端分析同意版本及自動取得的短期匿名 session，另以工作階段儲存保留跨分頁共用的分析計數與冷卻時間。使用者主動啟用時另暫存有限的診斷事件（階段、狀態、分類旗標與分數，不含貼文內容或憑證），可清除與匯出。不使用 Chrome 同步，session 僅可信任擴充功能環境可讀取。
- facebook.com：辨識首頁貼文與右側廣告卡片並加入遮罩，讀取已載入文字和圖片。
- fbcdn.net：下載貼文與廣告靜態圖片，沒有 Facebook Cookie、不跟隨轉址，縮圖後分析。
- 正式服務 HTTPS 主機：請求短期匿名 session、分析及服務狀態。實際主機為 fb-content-guard.wolkesau.workers.dev；不要求 localhost 權限。
- 無遠端可執行程式碼：服務只回傳 JSON 分類結果和短期憑證，沒有遠端 JavaScript、Wasm 或 eval。

## 資料揭露更新

使用者貼文與廣告內容會由開發者部署於 Cloudflare 的服務暫時處理，再轉交 OpenAI。維持對貼文可能含個人識別、健康、財務／付款、通訊及位置資料的保守揭露；另說明匿名 session、網路 IP 及其派生碼的防濫用用途，不可宣稱無後台接收資料或完全匿名。

隱私權網址沿用 `https://wolke.github.io/fb-content-guard/privacy-cloud.html`，新版政策包含右側廣告、跨分頁排程與本機加強圖片檢查的說明。上傳時沿用既有資料揭露，並核對三項聲明與實作一致。

## 審查測試方式

沒有登入帳號、沒有配對碼，也不需要 Node.js 或個人 API key。安裝擴充功能，閱讀並同意雲端分析、儲存後重新整理已登入的 Facebook 首頁。先隱藏已辨識貼文與右側廣告卡片，完成分類後顯示或保持隱藏。可測試廣告換圖、換字或重新載入後會再次檢查。正式版不顯示除錯卡片；可在設定頁查看狀態、停用或撤回同意。斷網、超額或無法讀取圖片時，未檢查內容應維持遮擋。影片只檢查封面或單張畫面，通過後仍需手動選擇播放；不代表整段影片安全。

正式服務已啟用，健康檢查及安全合成文字／圖片已通過真實 OpenAI API 測試。免費用量受到限制，達限時請稍後重試。0.2.5 已通過 57 項程式測試與 34 項瀏覽器情境，Worker/D1 驗證及正式後台合成文字診斷測試亦通過；完整 CI 與真實 FB 端到端驗收結果另見版本紀錄。截圖為合成測試動態牆與模擬分類，沒有使用真實使用者貼文。

本機實驗功能測試：在設定按「開啟本機模型設定」，按「下載／啟用本機模型」並等待就緒，返回設定勾選「加強圖片檢查」後儲存。請保留模型分頁；不支援的電腦不要開啟此選項。雲端放行的圖片再送本機檢查，關閉模型分頁或結果不確定時，尚未完成的圖片貼文保持隱藏。這不是專用 OCR；普通風景示意圖曾回傳不確定，會多擋正常內容，功能預設關閉。Chrome 模型由瀏覽器下載，擴充功能沒有下載遠端 JavaScript／Wasm。


診斷測試：從 popup 開啟「查看 API 與判定紀錄」，勾選記錄診斷，再瀏覽新 FB 貼文或重新整理；展開貼文編號查看時間線，測試篩選、清除、匯出 JSON、關閉後清除。只記錄啟用後的新嘗試，舊資料無法補回。實際使用者安裝的 0.2.5 全流程尚未完成驗收，不宣稱分類準確率。
