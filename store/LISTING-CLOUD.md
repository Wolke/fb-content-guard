## 商品說明

清朗會先遮住已辨識的 Facebook 首頁貼文，在你同意後，將文字與縮小的靜態圖片交由清朗雲端服務和 OpenAI 分析色情內容。未被模型標記的內容會顯示；檢查中、疑似色情、無法檢查或達到服務用量上限的貼文直接隱藏，不在動態牆顯示錯誤卡片或佔位。

不需要登入，不需要 API key、配對碼或安裝其他程式。第一次安裝請閱讀雲端資料處理說明並主動同意，再重新整理 Facebook 首頁。你可以隨時撤回同意或關閉遮擋。

只適用桌面版 Facebook 首頁的文字、已載入靜態圖片及影片預覽。影片先檢查封面或可讀取的單張畫面，通過後顯示靜態預覽；整段影片尚未檢查，需要手動選擇播放。有「查看更多」或更多照片時，先檢查目前載入的部分；展開後再檢查新增內容，不會自動展開整則貼文。不支援 Reels 專用頁面、動態圖片、群組、Messenger 或手機 App。圖片完整畫面縮小後分析，可能影響細節判斷；模型和貼文辨識可能誤判、漏檢，無法保證完全阻擋色情。這不是無法繞過的家長監護工具。

免費服務有用量及速率限制，可能暫時無法使用。只調整本機顯示，不自動向 Facebook 隱藏、檢舉或發送訊息。與 Meta、Facebook、OpenAI 無官方隸屬關係。

## 權限理由

- storage：保存功能開關、雲端分析同意版本及自動取得的短期匿名 session。不使用 Chrome 同步，session 僅可信任擴充功能環境可讀取。
- facebook.com：辨識首頁貼文並加入遮罩，讀取已載入文字和圖片。
- fbcdn.net：下載貼文靜態圖片，沒有 Facebook Cookie、不跟隨轉址，縮圖後分析。
- 正式服務 HTTPS 主機：請求短期匿名 session、分析及服務狀態。實際主機為 fb-content-guard.wolkesau.workers.dev；不要求 localhost 權限。
- 無遠端可執行程式碼：服務只回傳 JSON 分類結果和短期憑證，沒有遠端 JavaScript、Wasm 或 eval。

## 資料揭露更新

使用者貼文會由開發者部署於 Cloudflare 的服務暫時處理，再轉交 OpenAI。維持對貼文可能含個人識別、健康、財務／付款、通訊及位置資料的保守揭露；另說明匿名 session、網路 IP 及其派生碼的防濫用用途，不可宣稱無後台接收資料或完全匿名。

隱私權網址改為 `https://wolke.github.io/fb-content-guard/privacy-cloud.html`，已確認公開可讀且移除草案標示，商店欄位已儲存。三項聲明與實作一致。

## 審查測試方式

沒有登入帳號、沒有配對碼，也不需要 Node.js 或個人 API key。安裝擴充功能，閱讀並同意雲端分析、儲存後重新整理已登入的 Facebook 首頁。先隱藏已辨識貼文，完成分類後顯示或保持隱藏。正式版不顯示除錯卡片；可在設定頁查看狀態、停用或撤回同意。斷網、超額或無法讀取圖片時，未檢查內容應維持遮擋。影片只檢查封面或單張畫面，通過後仍需手動選擇播放；不代表整段影片安全。

正式服務已啟用，健康檢查及安全合成文字／圖片已通過真實 OpenAI API 測試。免費用量受到限制，達限時請稍後重試。截圖為合成測試動態牆與模擬分類，沒有使用真實使用者貼文。
