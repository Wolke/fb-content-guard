# 0.2.5 — API 呼叫與判定診斷

狀態：程式、正式與開發 ZIP、完整 CI、雲端診斷部署及公開政策已完成。0.2.4 已提交審查，0.2.5 尚未上傳或送審。

## 使用方式

1. 重新載入新版擴充功能，開啟清朗 →「查看 API 與判定紀錄」。
2. 勾選「記錄診斷與背景 debug 訊息」，再到 Facebook 瀏覽新內容。只記錄新嘗試，過去結果無法補回；重新整理 FB 可能重新消耗額度。
3. 展開貼文編號，查看前置檢查、圖片處理、匿名 session、清朗雲端、OpenAI、本機 Gemini Nano、快取與最後顯示狀態。
4. 可篩選失敗／不確定、隱藏、模型阻擋、已顯示，手動或每 3 秒更新、清除、匯出 JSON。
5. 啟用期間，擴充功能 Service Worker 主控台同步輸出 `[清朗診斷]` 的安全欄位；不是 Facebook 網頁主控台。

## 判定與隱私

- 不改變分類門檻或未完成保持隱藏的規則；正式版動態牆仍沒有診斷卡。
- 區分發出請求、收到 HTTP 回覆、後台確認的 OpenAI 明細，以及沒有提供明細。未記錄送出不能反推過去沒有請求。
- 後台診斷為選填、向後相容；只在 diagnostics=true 時回傳有限欄位。每張顯示 API HTTP、耗時、sexual/sexual-minors 旗標與分數（提供時），不增加模型呼叫。
- 本機模型提供逐張 ALLOW/BLOCK/UNCERTAIN、錯誤代碼及耗時，不把它描述為有可信度分數。
- 預設關閉；只存 Chrome session、最多 600 筆事件；讀寫時移除超過 6 小時紀錄。關閉、清除、瀏覽器結束即清除。匯出與背景主控台副本需另行管理。
- 嚴格白名單，不記錄貼文文字、圖片、網址、金鑰、憑證、provider 原始回覆。清除／關閉後舊請求不能補寫；只有擴充功能自己的診斷頁能啟用或讀取完整紀錄。
- Popup 將「遮擋」改成「判定阻擋」、「無法讀取」改成「檢查未完成」，並提示模型未連線會讓圖片貼文停在雲端呼叫前。
