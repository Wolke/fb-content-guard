# 0.2.3 右側贊助廣告

日期：2026-11-03。尚未安裝至使用者 Chrome、尚未提交 Chrome Web Store。

問題：原本只掃描首頁動態牆貼文，右側贊助廣告不在掃描範圍。截圖無法證明該廣告曾被分類為正常。

- 新增 RightRail／Sponsored pagelet，以及有「贊助／Sponsored」標題的 complementary 區域中的圖片廣告連結辨識。
- 廣告卡片各自送文字與圖片檢查，沿用既有同意、限流、排隊、快取與判斷流程。不送出廣告的目的地 URL。
- 未完成、等待額度、讀取失敗、判定需遮擋的卡片，正式版維持隱藏；開發版保留診斷卡片。
- 右側好友邀請、聯絡人的 Facebook 個人檔案連結不送分析。
- 更換廣告文字、圖片或目的地會重新檢查；動態插入的廣告也先遮擋。
- 設定頁、隱私權政策來源檔已更新掃描範圍；未變更後台額度。發布狀態另見 SUBMISSION-STATUS.md。

限制：目前支援可辨識的圖片廣告卡片。這次沒有可用的 Chrome 操控工具，尚未取得使用者真實 FB DOM 進行驗收；Facebook 不同版面或新結構仍可能漏掃。本次修正掃描範圍，未調整色情分類門檻，不保證所有性暗示廣告都會判為色情。

驗證：[GitHub CI](https://github.com/Wolke/fb-content-guard/actions/runs/41592626111) 已通過完整邏輯測試、Worker／D1 runtime、打包與 31 項瀏覽器情境。另有 17 項相關背景／限流測試於本機通過。測試使用合成頁面與模擬分類，不會送出真實 Facebook 內容。正式版及開發版 ZIP 已產生。
