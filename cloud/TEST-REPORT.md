# 0.2.0 雲端改版驗證紀錄

日期：2026-10-15。環境：Node.js 24、獨立無頭 Chrome、Cloudflare Wrangler／本機 workerd 與 D1。

## 驗證範圍

- Node 模擬測試：37 項通過，涵蓋匿名 HMAC、到期／換日／換 IP、單一 SQL 原子配額、資料庫重連／重啟、並發限額、失敗計額、設定開關、同意版本、固定 API、資料大小及敏感錯誤處理。
- Chrome 合成動態牆：13 個情境通過，包括先遮擋、內容換入撤銷舊結果、手動顯示、重試、沒有同意不送出、開關、快取、多圖、影片／未知媒體及雲端設定介面。
- 原生 Chrome 圖片處理：1600×800 合成圖完整縮為 512×256 JPEG，符合 128 KiB 上限，未裁切。
- Wrangler 編譯與本機 workerd 實際執行整合測試通過：匿名 session、HMAC、D1 migration、圖片 payload、分類服務邊界，以及 6 筆同時請求僅 2 筆取得測試配額。
- 未設定雲端網址時正式打包被拒絕；開發包可產出，名稱清楚標示「開發測試，勿上架」。

## 不代表已完成的事項

所有分類回應皆為測試替身。未使用真實 Facebook 貼文或 OpenAI API key。尚未在已登入的使用者 Facebook 頁面驗證選擇器／快速捲動／準確率；沒有公開 Workers 部署或 Cloudflare Free CPU 用量實測。

免費服務容量、實際延遲、圖片縮小對分類的影響，以及目前商店審查／發布狀態，都不能由這些測試推定。正式上線前須依 DEPLOY.md 完成驗收。
