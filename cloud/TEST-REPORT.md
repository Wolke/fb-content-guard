# 0.2.0 雲端改版驗證紀錄

日期：2026-10-15。Node.js 24、獨立無頭 Chrome、Cloudflare workerd／D1、使用者已登入 Chrome。

- Node 測試 40 項通過，包括匿名 session、同意撤回、資料邊界、上游錯誤、原子用量及逐張圖片分類。
- Chrome 合成動態牆 17 個情境通過，包括新 Facebook aria-labelledby／data-virtualized 容器、留言巢狀去重、SVG 頭像、表情文字、內嵌 SVG、背景圖、先遮擋、晚到回應、手動顯示及重試。
- 原生 Chrome 圖片測試：1600×800 完整縮為 512×256 JPEG，未裁切、符合大小上限。
- 本機真實 workerd／D1 整合通過；6 筆並行請求僅 2 筆取得測試額度。SQLite 另外驗證多圖整批預留不可部分成功或超額。
- 正式 Worker／D1／OpenAI：安全文字、單圖、雙圖皆 HTTP 200 allow。多圖請求最初被上游 HTTP 400 拒絕，已改為逐張分類並按張預留額度。
- 真實 Facebook 發現舊選擇器只遮留言而漏主貼文，已修正並確認整則遮罩、手動顯示、展開後重新檢查；DOM 最終狀態確認真實貼文為 allow（非 manual）；未展開文字、影片及空白載入容器保持遮擋。
- 正式 ZIP 已驗證版本、檔案清單、秘密樣式掃描及精確 HTTPS 主機權限。

限制：未建立色情樣本準確率／快速捲動漏檢的系統性評測；控制台 CPU 尚無可用數據，未確認排程第一次執行結果。合成商店截圖不是實際 Facebook，也不是模型準確率證明。免費容量與延遲不保證，圖片縮小可能影響細節判斷。
