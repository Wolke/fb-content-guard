# 雲端免登入改版執行計畫

日期：2026-10-15。分支：cloud-migration。目標版本：0.2.0。

使用者要求所有人可安裝、免登入，優先免費服務。依建議選擇 Cloudflare Workers Free＋D1 Free；GitHub Pages 繼續作靜態網站。若帳戶條件／免費 CPU 限制不符，先回報，再討論 GAS 或其他替代，不升級付費。

## 執行順序

1. 完成雲端後台：自動簽發短期匿名 session、到期驗證、綁定當日 IP 派生碼、持久且原子的全站／session／IP 額度限制，固定 OpenAI 分類端點；不儲存貼文。
2. 完成擴充功能：移除配對碼、localhost 和 npm 指示；使用固定部署網址、自動連線、版本化的雲端分析同意及清楚的暫停原因。升級後不得沿用舊本機分析同意。
3. 完成部署工具及發行檢查：秘密設定留在後台；沒有部署網址、未確認雲端版本可用時不產生商店發行包。測試包必須明確標示。
4. 測試匿名 session、quota 競爭／重啟、拒絕來源、資料大小、錯誤不放行、撤回同意、重複請求、合成 Facebook DOM。再驗證 Workers 實際執行環境。
5. 更新網站、隱私政策、商店文案及審查步驟。當前 0.1.0 的政策與 0.2.0 草案分開，部署切換時才發布雲端資料處理聲明。
6. 在專案擁有者的 Cloudflare 免費帳戶部署，設定 OpenAI key 與服務秘密；實測雲端＋Chrome＋Facebook，再上傳新版商店套件。

## 初始服務限制（可調低）

初始全站分析預算為每日 1,000 次、每分鐘 15 次，包含失敗嘗試；IP 每分鐘 5 次、每日 200 次；匿名 session 每日 100 次。session 有效一小時，換日／換 IP 自動重取。session 簽發也有限流。這些是保護值，不是服務人數承諾，實際仍受 OpenAI 專案 RPM／TPM／RPD 與 Workers／D1 配額限制。

免登入無法確保每個人只有一份額度；分散式濫用仍可能消耗免費配額。因此全站硬上限與服務停用開關不可省略，額度不足時暫停，不切換付費模型。匿名 token 不證明是真實 Chrome 安裝。

## 外部條件

- Cloudflare 帳戶登入與允許本專案部署；確認使用 Free 方案。
- OpenAI API key 透過後台秘密欄位／隱藏輸入設定，不貼聊天。
- 正式服務 URL 和商店 extension ID；未部署前只有明確不可發行的開發設定。
- 實際 Facebook 測試內容需要使用者同意送至自己的雲端服務及 OpenAI；不擅自讀取其他帳號或聊天。

## 完成判準

完全沒有 Node.js 的乾淨 Chrome 使用者環境，能安裝、同意、分析；拒絕／撤回同意不再送出新貼文；沒有金鑰出現在 ZIP；沒有 localhost 權限；配額在重啟後仍有效；政策與實際資料流一致。只通過模擬測試不能宣稱完成公開服務。
